A2A — Agent-to-Agent Protocol

Enables autonomous agent discovery, task delegation, and result sharing. Agents announce capabilities via Agent Cards and communicate through standardized JSON-RPC messages.

Anthropic

MCP — Model Context Protocol

Provides structured access to external tools and data sources. Each agent exposes its capabilities as MCP tools, enabling the orchestrator to invoke specialized functions.
